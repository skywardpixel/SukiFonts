# SukiFonts

SukiFonts adds two clean, highly-readable fonts to your UI font library ([LibSharedMedia-3.0](https://www.wowace.com/projects/libsharedmedia-3-0)), so you can use them in any addon that supports custom fonts.

## Fonts included

- **Atkinson Hyperlegible Next** — a font specifically designed for maximum legibility, with distinct letterforms that are easier to distinguish at a glance (no more confusing a lowercase "l" with a capital "I"). Great if you want sharper, easier-to-read text in chat, nameplates, unit frames, or damage meters, especially at small sizes or on high-resolution monitors.
- **Cabin** — a clean, modern humanist sans-serif font with a friendly, rounded feel. A good alternative to the default WoW font for players who want a more polished, less "blocky" look across their UI.

## What this addon does

SukiFonts doesn't change any fonts by itself — it's a font library. Once installed, both fonts automatically appear in the font selection dropdown of any addon that uses LibSharedMedia-3.0 (for example ElvUI, SUI, WeakAuras, Details!, Bartender4, and many others). Just install SukiFonts, then pick "Atkinson Hyperlegible Next" or "Cabin" from your favorite addon's font options — no configuration needed on SukiFonts' end.

## Why use it

If you're tired of the default Friz Quadrata / Arial font choices and want something cleaner or easier on the eyes, SukiFonts gives you two solid, free (Open Font License) options without having to manually install `.ttf` files into other addons' font folders.

## Installation

1. Download and extract SukiFonts into your `Interface/AddOns` folder.
2. Make sure it's enabled at the character select / addon list screen.
3. Open the font settings of any addon that uses LibSharedMedia-3.0 and select "Atkinson Hyperlegible Next" or "Cabin".
